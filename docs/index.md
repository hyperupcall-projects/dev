# dev

 It helps with developing software and managing my computer. You're able to:

 - Create projects from a template
 - Manage the configuration and tooling of projects
 - Run one-off scripts

At a high level, there are separate parts:

- A CLI for managing repositories.
- A website for managing desktop systems.
- Small one-off tools.
- Modules for managing other frameworks/technologies for use on this computer.

See more about the [CLI](./docs/cli.md).
